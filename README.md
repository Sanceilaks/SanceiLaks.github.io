# voidptr_t

Personal landing page. SvelteKit, static build, GitHub Pages.

```sh
npm install
npm run dev
npm test
npm run build
```

GitHub Pages must be built from **GitHub Actions**, not from the `master` branch root. After the first workflow run: **Settings → Pages → Source → GitHub Actions**.

`static/CNAME` keeps the custom domain (`voidptr.su`). `static/keybase.txt` stays at the site root.
